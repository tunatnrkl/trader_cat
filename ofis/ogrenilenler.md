# Öğrenilenler — "Ne oldu → Doğrusu → durum"

- Yalnız renk değiştiren "yeniden tasarım" reddedildi → biçim/düzen/tipografi birlikte değişmeli → kesin
- Olgunlaştırmak için doygunluğu kısmak (grafit/mat) "cansız" bulundu → ciddiyeti ORANLA (ince kontur, küçük köşe/basamak, font ağırlığı) ayarla, rengi koru → kesin
- Gri/soluk mor tonlar "soluk" bulundu → koyu lacivert zemin + doygun kobalt/altın/nane → kesin
- Tasarımcı oneri.diff'i olduğu gibi uygulamak QA düzeltmelerini geri alacaktı → yalnız ilgili parçaları uygula, diff'i gözden geçir → kesin
- Paralel ajanlar aynı scratchpad dosyasına yazdı → her ajana ayrı klasör → kesin
- Coin eşiğini %50 artırmak toplam süreyi yalnız %4–9 uzattı → Kat.1'de engel nakit, sonra Bobby/robot/kaldıraç kârı katlıyor; eşik tek başına zayıf kaldıraç → kesin (sim, 2 koşu)
- Ofis yöneticisi hızlı küçük modelle pasif kaldı → yönetici Opus/yüksek efor + proaktif hedef → deneme
- Rate limit sonrası ajanı yeniden başlatmak yerine SendMessage ile devam ettirmek bağlamı korudu → kesin
- Aynı dosyada iki ajan farklı bölgelere dokunarak paralel çalıştı, sorun çıkmadı ama risk var → yeni kural: Yazılımcı/Görsel/Ses sırayla → kesin (prompt kuralı)
- Oyun tasarımcısı Kat.1 eşiğini 150→100 indirdi, iyi oyuncu hızlandı; kullanıcının "%50 daha yavaş" kararına ters → kullanıcı kararlarını brifte "DEĞİŞMEZ" diye yaz, iyi oyuncu için "hiçbir geçiş hızlanmaz" kuralı → kesin
- sim.js varsayılanları oyundan sapmıştı (Pebble Sv.1 / kaldıraç ×2; oyunda Sv.2 / ×1), teşhis süreleri ~%6 şişti → ölçmeden önce sim varsayımlarını oyunla karşılaştır → kesin
- Testçi botu Pebble'da kaldı, coin değiştirmedi → teşhiste bot coin geçişi de yapsın → deneme
- Sim'de Kat.1 %23 kısaldı ama Testçi puanı değişmedi: botlar mağazadan hiç almadı ve 1–5 ölçeği küçük gelişmeyi göstermiyor → teşhis botu mağaza alımı da yapsın; puanla birlikte ölçülebilir göstergeler (dk, mama dönüşü) de raporlansın → deneme
- Kurtarma turu bilgisayar onarılmadan önce de açılıyordu (S.fix kontrolü yoktu); Testçinin "açılışta mama gerekmedi" notundan yakalandı → oyuna yeni kapı eklerken açılış (S.fix=0) durumunu da test et → kesin
- Görsel tasarımcı "telefonda sıkıştırdım" dedi ama gerçek iPhone boyutunda kartlar hâlâ 3 satırdı; bitiş kartı iPhone'da taşıyordu → telefon işini Playwright cihaz taklidiyle (iPhone 15 Pro / SE yatay) ekran görüntüsünde Yönetici kendisi görmeden kabul etme → kesin
